# Week 1: Text Tokenization with NLTK

## Project Overview
This project demonstrates basic text tokenization using Python and the NLTK library.

## Objectives
- Split a paragraph into sentences.
- Split text into individual word tokens.
- Count sentences and word tokens.
- Display numbered sentences and tokens using `enumerate()`.

## Technologies
- Python
- NLTK

## How to Run
1. Install NLTK:
   `pip install nltk`
2. Run the program:
   `python main.py`
3. Enter a paragraph when prompted.

## Concepts Learned
- `sent_tokenize()`
- `word_tokenize()`
- `len()`
- `enumerate()`
- Python loops and f-strings
